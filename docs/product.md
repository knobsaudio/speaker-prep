This app is a minimalist way to pass a stereo pair through a single effect. For
example, the user could select their audio interface, channels 3-4, and Goodhertz
CanOpener Studio. Any audio going to channels 3-4 of their audio interface would be
tapped and passed through the effect (the user can open the effect and change
parameters) and then the resulting stereo audio is passed back to channels 3-4 for
output.

The app lives in the menu bar. Opening the dropdown shows the device, channel,
and effect pickers, Start/Stop, status for the effect and the tap, a launch-at-
login toggle, and Quit. Selections and plugin parameters persist across
launches, and a tap that was running resumes on launch.
